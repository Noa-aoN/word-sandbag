# 仕様メモ

## 目的

「誰にも送らない・どこにも残さない」を体験的に成立させる、ストレス手放し用のミニアプリ。

## コア体験

入力 → パンチ → 飛ぶ → 当たる → 揺れる → 消える → 入力欄が空になる。
1サイクルで完結し、履歴は持たない。

## 設計判断

### 保存しない

localStorage、sessionStorage、IndexedDB、外部API、Cookie、URL クエリのいずれにも入力テキストを載せない。
console 系にも入力内容を出力しない。
画面の状態として React のメモリにだけ保持し、アニメーション終了で破棄する。

### パンチ威力

- 1〜10文字: light
- 11〜40文字: normal
- 41文字以上: heavy
- `!` `！` `?` `？` の合計が3つ以上で1段階アップ

威力で揺れ幅・移動距離・効果音文字（ポンッ / バシッ / ドゴッ）を切り替える。

### 演出のタイミング

文字を投げ出してから約 0.4〜0.5 秒後にサンドバッグの揺れとヒットエフェクトを発火させる。
即時揺らすと「飛ぶ前に当たっている」ように見えるため。

### a11y

- `prefers-reduced-motion` 時は移動アニメを最小化（フェードのみ）
- ボタン / textarea に `aria-label`
- 完了メッセージ・ヒット数は `aria-live="polite"`
- IME 変換中の Enter は確定として扱わない（`isComposing` チェック）

## 技術選定

### React + Vite + TypeScript

GitHub Pages 配信できる軽量な静的アプリで十分。バックエンドは要件にない。
React のフック1つで状態が完結する規模なので、状態ライブラリは不要。

### Framer Motion

数行で reduced-motion を扱え、`AnimatePresence` で要素退場を表現しやすい。
CSS Animation だけでも書けるが、複数の同時アニメ（飛ぶ / 揺れ / 消える）を組むには記述量が増えるため採用。

### pnpm

兄弟アプリと揃えたわけではなく、ローカルで pnpm が常用される前提に従っただけ。
このアプリ単体としても、依存数が少なくランタイム要件もシンプルなので pnpm の高速さで十分。

### ポート

`m-w-05` 規則に従い 3050 を使用（兄弟と揃えるためではなく、衝突回避ルールに従ったもの）。

## 却下した選択肢

- **localStorage でセッション中のヒット数を永続化**: 「保存しない」原則を曖昧にするため却下。タブを閉じれば 0 に戻る挙動を維持。
- **AI による感情分析・キーワードハイライト**: コンセプトと逆行。診断風になる懸念あり。
- **SNS シェアボタン**: 入力テキストを外に出してしまう導線になるため不採用。
- **音声 SE ファイル**: GitHub Pages に置くアセットを増やしてまで実装する必要なし。視覚エフェクトと（対応端末では）`navigator.vibrate` で代替。
