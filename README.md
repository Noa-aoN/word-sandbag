# 言葉サンドバッグ

誰にも送れない言葉を、サンドバッグにぶつけて消すミニアプリ。

## コンセプト

SNSに書くほどではない。誰かに送ると角が立つ。でも自分の中には残したくない。
そんな言葉を入力して、パンチするだけ。
言葉はサンドバッグへ飛び、当たって、消えます。

入力した言葉は保存されません。

## 主な機能

- テキスト入力 → パンチで消す体験
- 文字数に応じたパンチ威力（light / normal / heavy）
- `!` `？` 等の記号が多い時は1段階強い演出
- サンドバッグの揺れ、ヒットエフェクト
- セッション中のみのヒット数表示（再読込でリセット）
- `prefers-reduced-motion` 対応

## 技術スタック

- React 19
- Vite 7
- TypeScript 5
- Framer Motion

## 必要環境

- Node.js 20 以上
- pnpm 10 以上

## セットアップと起動

```sh
pnpm install
pnpm dev
```

dev サーバは `http://localhost:3050` で起動します。

## ビルドとプレビュー

```sh
pnpm build
pnpm preview
```

## 保存しない設計について

このアプリは入力された言葉を一切保存しません。

- localStorage / sessionStorage / IndexedDB を使いません
- 外部APIへの送信、メール送信、SNS投稿はありません
- 入力テキストを `console` に出しません
- URL クエリにも載せません

入力された言葉は React のメモリ上に保持され、画面アニメーションが終わったら破棄されます。タブを閉じれば全て消えます。
