# 言葉サンドバッグ

吐き出したい言葉を、ブラウザの中のサンドバッグにぶつけて消すミニアプリ。

SNS に書くほどではない、誰かに送ると角が立つ、でも自分の中に残したくない。
そんな言葉を打ち込んで、パンチで殴って、消す。
入力した言葉は **どこにも保存されません**（タブを閉じれば全部消えます）。

## できること

### 言葉パンチ
- テキストエリアに言葉を入力して **「言葉パンチする」** ボタン or Enter で発射
- 文字が左右から飛んできて、サンドバッグに着弾、砕けて消える
- 文字数で威力が変わる（短い＝軽快なポンッ、長文＝重いドゴッ）
- `!` `?` `！` `？` を 3 つ以上含むと強調モードで一段階強い演出

### プリセットパンチ（左パネル）
よくある気持ちをワンタップで:
- 泣き言（コード）: バグだ / なにもわからん / ビルド通らん / もう無理
- 怒り: なんでだよ / ふざけんな / ぶっとばす
- 受容: まあいっか / ありのまま / それも自分
- 感謝: おつかれさま / 助かった / ありがとう
- 長い言葉: 「スリランカの首都」「ピカソの本名」など、ボタン文言は短いけど打つと正式名称（とても長い）が一気に飛んでいくネタ系

### 技（右パネル「操作」セクション）
- **フック**: 横から大きく振り抜く
- **アッパー**: 下から打ち上げ、バッグが跳ね上がる
- **キック**: 強い側面打ちで深い凹みが残る
- **クランチ**: 抱きしめる用のソフトな演出（揺れもサウンドも穏やか）

### 特殊パンチ
- **猫パンチ**: 肉球が飛んできて「にゃっ」
- **札束パンチ**: 福沢諭吉の束で「ドサッ」と紙をはたく音

### サンドバッグ自体への操作
- バッグを **直接クリック / タップ** で打てる（場所依存の凹みが残る）
- **ドラッグして引っ張る** と振り子のように戻る
- 300 発でバッグが千切れて飛んでいき、新しいのが補充される（ガチャン音つき）

### タオルを投げる
途中でやめたいときの **棄権ボタン**。タオルが画面を横切って飛んでいき、その時点の言葉パンチがすべて中断される。

### 設定（右パネル）
- **音 ON / OFF**: すべての効果音（Web Audio API でその場合成、外部音源は使ってない / 猫の鳴き声だけ CC0 録音）
- **パンチ速度**: 4 段階（ゆっくり / ふつう / はやい / 全力）。文字の飛んでくる速さとパンチ間隔
- **パンチ強度**: 4 段階（弱め / ふつう / 強め / 全力）。**位置は変えず** に凹みの大きさ・効果音文字（ポン → バシッ → ドゴッ → ドガーン!! など）・効果音の重み・揺れ幅だけが変わる

### 配慮されているもの
- **入力した言葉はどこにも保存しない**（後述）
- **prefers-reduced-motion** に対応（OS 設定でアニメ控えめが選ばれていれば動きを最小化）
- 入力サニタイズ（制御文字・不可視文字を弾く）
- IME 変換中の Enter は確定として扱わない
- スマホ縦持ちは 1 列、PC 横持ちは 4 パネル（左 / 中央上下 / 右）

## 保存しない設計について

このアプリは入力された言葉を **一切外に出しません**。

- localStorage / sessionStorage / IndexedDB を使わない
- 外部 API への送信なし、メール送信なし、SNS 投稿なし
- 入力テキストを `console.*` に出さない
- URL クエリにも載せない

入力テキストはメモリ上にだけ保持され、アニメーション終了か **タブを閉じた時点** で破棄されます。

## 動かし方

```sh
pnpm install
pnpm dev
```

ブラウザで `http://localhost:3050` を開いてください。

ビルド + ローカルプレビュー:
```sh
pnpm build
pnpm preview
```

## 今後やりたいこと

- **タイピングモード**: 入力したお題テキストを正しくタイピングしながら一文字ずつパンチを打ち込んでいく、タイピング練習 + ストレス解消の合わせ技モード
- **音ゲーモード**: BGM のリズムに合わせて流れてくるノーツに合わせてパンチを打つ、リズムゲーム的なモード

両方ともデータは引き続き保存しない方向で計画。
